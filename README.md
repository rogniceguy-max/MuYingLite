# 沐影库

一个局域网内使用的影视项目协同工作台。项目按集组织，每集一张节拍表，整个项目一张资产表；视频与图片进入项目文件库，可被多行复用；多人实时协同、完全匿名、无登录；删除进入按批次管理的回收站。

规格文档：[docs/SPEC.md](docs/SPEC.md)

## 现在能做什么

- 统一视觉系统：颜色、字号、间距、圆角、动效使用同一套 CSS token；浅色为暖中性纸白，深色为中性石墨，强调色为琥珀金
- 全局使用自托管 MiSans（Regular / Medium / Semibold，700 映射到 600）：菜单/下拉选项和标题 18px，正文/表格单元格/按钮/侧栏 16px，表头/说明文字/徽标/计数/状态胶囊 14px
- 项目内页面（节拍表、资产表、文件库、回收站、项目设置）共享顶栏面包屑和 24px 内容边距；节拍表、资产表、文件库、回收站铺满工作区，不再有 1680px 最大宽度；表格列宽按比例自适应，1280 / 1440 / 2560 均不出现横向滚动，列变窄时换行、行高增加；项目列表保留独立的 Root 页头
- 表格与文件库按视口高度填充，滚动条预留空间；首屏前应用主题，图片容器预留尺寸，减少加载和切换时的布局跳动
- 品牌图标使用透明底 Aqua 3D 胶卷/金色夕阳插画，自托管 WebP/PNG；字标、favicon、空状态标识统一；动效使用 140/180ms ease-out，并尊重 `prefers-reduced-motion`
- 项目列表与进入项目；Root 页头不显示“新建项目”按钮，空状态和项目网格仍可打开新建项目对话框
- 新建项目默认创建第 1 集、该集 8 行节拍表和一张资产表；文件库默认显示 `成片` 文件夹及按集划分的子文件夹（虚拟文件夹，首次上传时创建物理目录）
- 新增一集，自动创建该集的 8 行空白节拍表，并自动增加该集的 `成片 / 第X集` 文件夹
- 节拍表固定列：
  - 场景（文本）
  - 节拍（只读序号，按行顺序）
  - 故事内容（长文本）
  - 标注（红 / 黄 / 绿 / 空）
  - 规划（长文本）
  - 批注（文本框 + `@` 当前行媒体）
  - 视频（一个节拍多条的媒体引用）
- 资产表固定列：
  - 类别、名称（文本）
  - 集数（多选 episode，点击跳转对应节拍表）
  - 选定（唯一图片）
  - 备选（多张图片，可排序）
  - 批注（文本框 + `@` 当前行媒体）
- 图片预览中“设为选定”：备选变成选定，原选定自动回到备选
- 视频播放器：播放/暂停、进度、音量、全屏、倍速
- 图片灯箱：滚轮以鼠标位置为中心缩放，放大后拖动平移，双击重置；不显示缩放工具栏
- 视频卡片、选定图、备选图：点击播放/预览；选定图右键“更换 / 移到备选”，视频/备选右键移除
- 视频/备选单元格不显示播放胶囊、上移/下移按钮、添加按钮、文件名 caption；拖拽上传，右键空白区域可从文件库添加，右键媒体项移除
- 空白单元格不显示占位提示文字
- 侧栏只显示集号/标题，不显示表名；集条目右键管理，不显示更多图标按钮
- 顶栏面包屑显示 `第X集 · 集标题`；资产表页显示“资产表”
- 表格页不显示独立工具栏，添加行按钮位于表格底部并居中
- 资产表无选中图时显示“选择图片”；有选中图时不显示“更换”按钮，右键缩略图“更换 / 移到备选”；“移到备选”只把引用移回备选列，不删媒体、不进回收站
- 资产表集数行内最多显示 2 个胶囊 + `+N`；点 `+N` 打开隐藏集的导航菜单，每个隐藏集可跳转；已删除的集不显示、不计数；集数选择菜单也不显示已删除集；菜单按集号排序
- 项目文件库采用 Windows 资源管理器式大图标网格，无左侧文件夹树：
  - 文件夹卡片：`第X集 / 第X拍`、`资产表 / 类别 / 名称 / 选定|备选`、`成片 / 第X集`、`文件库`
  - 文件卡片：大缩略图或媒体图标、文件名、类型与大小
  - 单击选中，双击文件夹进入/文件预览
  - 支持从系统资源管理器一次拖入多个文件到当前文件夹；按当前文件夹规则过滤类型，上传时显示拖放提示
- 文件库右键菜单：下载、重命名、删除
- 文件库文件夹右键：下载文件夹（ZIP）。ZIP 以被右键的文件夹为根目录，保留其下层级；右下角显示打包进度、文件数和已处理大小，打包完成后浏览器开始下载
- 视频拖拽上传：拖到节拍行任意单元格 → 该行视频列（只接受视频）；拖到资产行任意单元格 → 该行备选列（只接受图片，不会自动设为选定）
- 文件库顶部上传按当前文件夹生效：
  - `第X集 / 第Y拍`：只接受视频，存到该文件夹并自动挂到第 X 集第 Y 拍
  - `第X集`：只接受视频，存到 `未分拍`，不自动挂表
  - `资产表 / 类别 / 名称 / 选定`：只接受图片，存到角色文件夹并自动设为该资产行的选定图
  - `资产表 / 类别 / 名称 / 备选`：只接受图片，存到角色文件夹并自动追加到该资产行的备选
  - 每个资产行都会生成空的选定/备选虚拟文件夹，可直接上传
  - `成片 / 第X集`：只接受视频，可放多个成片文件，不自动挂到节拍表；`成片` 根位置也只接受视频，存到 `成片 / 未分集`
  - 文件库根位置：视频/图片都可上传
- 资产图片在文件库中按当前活跃引用的角色归入选定/备选文件夹；表内切换角色后刷新即移动显示
- 后端校验 MIME/扩展名与 `video`/`image` 一致，并校验节拍表视频列只收视频、资产表图片列只收图片，不能绕过前端上传错误类型
- 媒体单元格不再显示添加按钮；视频/备选用拖拽添加上传
- 侧栏项目名双击/右键重命名；品牌点击返回项目列表
- 集列表独立滚动，资产表/文件库/回收站固定在侧栏底部
- 项目卡片只显示项目名和集数，不显示序号/日期/表数量
- 媒体可被多行复用；删除行只解除该行引用，无其他引用的媒体才进回收站
- 回收站：
  - 与文件库一致的大图标网格，按全部/行/整集/媒体筛选
  - 整集批次显示为文件夹卡片，不再显示引用媒体缩略图条
  - 双击整集/行批次进入文件夹视图，按媒体存储路径显示节拍/类别文件夹；双击媒体可预览视频或图片
  - 文件夹内媒体不显示“已删除”徽标和“媒体已移入回收站”文案；共享媒体仍显示“仍在使用”
  - 文件夹/媒体卡片右键仍对整批“恢复 / 彻底删除”
  - 仍被其他表引用的媒体保留本体，只删除本批次引用；回收站中显示“仍在使用”标记
  - 卡片右键“恢复 / 彻底删除”，卡片内不显示操作按钮
  - 单批“彻底删除”只需普通确认；顶部“清空回收站”仍需输入 `DELETE`
  - 行批次：恢复行、引用、媒体
  - 整集批次：恢复集、节拍表、行、本批次删除的媒体
  - 媒体批次：恢复媒体到文件库
  - 彻底删除：移除数据库记录和本批次已删除的媒体原文件，不删除共享媒体本体
- 资产表单行备选缩略图按 68×50 换行；实测 11 张为 4+4+3 排列，行高约 179px
- 多人实时协同：
  - Yjs / Hocuspocus，字符级合并
  - 匿名彩色光标/单元格选中框
  - 断线自动重连，断线期间只读
- 行删除改为右键菜单（不再有行尾删除按钮），仍保留确认
- 黑色 / 白色双主题，右上角太阳/月亮切换；顶栏不显示设置图标，项目设置入口在侧栏底部
- 所有图标使用 Lucide
- 表名不再作为用户概念：
  - 集菜单、资产表、项目设置都不提供表改名
  - 内部 `sheets.name` 仅保留默认标签
  - 编辑集号/标题只改集元数据，不写 Y.Doc、不重连、不重挂载
- 完全匿名：没有用户、角色、登录、JWT、权限校验

## 快速启动

要求：Node.js 22+（项目在 Node 22.19 上开发）。

```bash
npm install
npm run build
npm start
```

打开：

```text
http://localhost:3001
```

协同 WebSocket：

```text
ws://localhost:1234
```

开发模式（Vite + API 热更新）：

```bash
npm run dev
```

前端开发地址是 `http://localhost:5173`，API 会代理到 `3001`。

Root 页头不显示“新建项目”按钮；空状态和项目网格可打开新建项目对话框。也可以通过 API 创建：

```bash
curl -X POST http://localhost:3001/api/projects \
  -H "Content-Type: application/json" \
  -d '{"name":"新项目","firstEpisode":{"number":1,"title":null}}'
```

创建后刷新 Root 即可进入。

- 旧演示数据已通过迁移脚本整理到上述嵌套结构。

## 与规格的差异（本地成品适配）

规格的生产方案是 **PostgreSQL + MinIO/S3 + FFmpeg + Docker Compose**。当前交付环境没有 Docker 和 FFmpeg，因此本地成品做了三处可替换的适配：

1. **数据库**：用 Node 22 内置 `node:sqlite` 代替 PostgreSQL。表结构、ID 语义、软删除/批次语义保持一致。
2. **媒体存储**：用本地 `data/uploads/` 代替 MinIO/S3；上传、缩略图、播放、删除生命周期一致。视频按浏览器可播放的 MP4 直接提供，不做服务端转码/HLS。
3. **表格组件**：MUI X Data Grid Community 对行拖拽和自适应行高支持不理想，按规格里的 fallback 改成自定义固定列表格 + dnd-kit，交互和数据边界不变。

要切回生产栈，替换点集中在：

- `apps/api/src/db.ts`（数据库连接与 schema）
- `apps/api/src/media.ts`（对象存储与媒体处理）
- `apps/api/src/collab.ts`（Yjs 持久化）
- 表格渲染层

前端页面、API 边界、Yjs 文档结构不需要重写。

## 当前边界

- 不做登录/权限/成员管理（可信局域网）
- 不做离线编辑
- 不做跨项目媒体复用
- 不做时间码批注、PSD/TIFF 预览、HLS/多码率转码
- 不做项目删除、导入/导出、Excel 式批量操作
- 不做通用电子表格（公式/透视/宏）

这些都在规格的“可后置/明确不做”范围内。
